# مصدر لوحة الكاتب

هذا المجلد هو مصدر اللوحة التي ينشرها workflow `preview` إلى
`/preview/admin/`. لا يقع تحت `static/` عمدًا، لذلك لا يدخل بناء المدونة ولا
يصل إلى الموقع الإنتاجي.

## ما يحتاجه المالك قبل النشر

1. ينشر وسيط Sveltia Authenticator ويأخذ عنوانه الحقيقي.
2. يبدّل قيمة `oauth_base_url` الوحيدة في `settings.json` من
   `OWNER_MUST_SET_OAUTH_BASE_URL` إلى عنوان HTTPS الحقيقي. لا يوضع أي سر هنا؛
   إعداد Sveltia ملف عام بطبيعته.
3. يشغّل:

   ```bash
   python3 tools/generate_cms.py
   python3 tools/check_cms.py
   python3 tools/check_controls.py --update
   ```

4. يضبط أسرار `PREVIEW_FTP_HOST` و`PREVIEW_FTP_USER` و`PREVIEW_FTP_PASSWORD`
   و`PREVIEW_FTP_DIR` في `blog-build`، ثم يشغّل workflow `preview` يدويًا.
5. يتحقق أن الدخول بلا كلمة مرور الاستضافة يرجع `401`، ثم يختبر GitHub OAuth
   وإنشاء مسودة باللغتين قبل تسليم الرابط للكاتب.

لا يمكن تسجيل الدخول عن بعد والقيمة ما زالت `OWNER_MUST_SET_OAUTH_BASE_URL`.
هذا مقصود: لم يُنشأ Worker أو تطبيق GitHub OAuth، ولم يُخمن أي عنوان لهما.

## بنية المحتوى

- المجموعة التحريرية الوحيدة هي `posts`، وتكتب في
  `zeroone01z21-alt/blog-content` على فرع `main`.
- كل مقال حزمة Hugo: `content/blog/<slug>/index.en.md` و`index.ar.md`، والصور
  داخل مجلد المقال نفسه.
- لا توجد مجموعة `categories` قابلة للتحرير. التصنيفات الستة عقد مركزي في
  `controls/schema.json`، وتظهر داخل المقال كقائمة ثابتة قيمتها slugs. إنشاء
  ملفات تصنيفات في مستودع المحتوى سيصنع مصدر حقيقة ثانيًا، لذلك رُفض مطلب
  الخطة القديم بعد تثبيت تصميم T8.
- `delete: false` و`duplicate: false`: لا زر حذف ولا نسخ مقال. الأرشفة هي
  البديل الآمن للحذف.

## قيود موثقة

- Sveltia لا تستطيع تحويل اختيار واحد ثلاثي الحالات إلى حقلي العقد
  `draft` و`archived`. لذلك تعرض مفتاح نشر ومفتاح أرشفة، وتشرح الحالات الثلاث
  بوضوح في دليل الكاتب.
- لا تستطيع جعل slug قابلًا للتحرير عند الإنشاء ثم قراءته فقط بعد أول نشر
  بإعداد ثابت. تغيير الرابط بعد النشر يبقى إجراءً استثنائيًا للمالك مع 301.
- Sveltia v0.179.0 توفر واجهة عربية، كما أن أسماء الحقول والتعليمات
  ورسائل التحقق في هذه اللوحة عربية.
- صفحة توثيق الحقول الحالية تكتب `minLength/maxLength`، بينما مخطط الحزمة
  الرسمي وكود v0.179.0 يقبلان `minlength/maxlength`. المولّد يتبع مخطط الإصدار
  المثبّت، وقد اختُبر `config.yml` عليه؛ راجع هذه النقطة عند الترقية.
- `preview.yml` يبني المسودات ويرفع `/blog/` و`/admin/`، لكنه يرفض الرفع ما
  دام OAuth placeholder أو أحد أسرار FTP مفقودًا. لا ينشئ Cloudflare Worker.
